# 🎮 **Ward21 Game Community Site** 🚀

Welcome to the official site for **Ward21**, an immersive indie horror game set in an abandoned hospital in post-apocalyptic Sri Lanka! This site is created to showcase the game and gather feedback from the community. Explore, share your thoughts, and get involved! 😱💬
You can view the live version of the site at: [ward21.info.gf](http://ward21.info.gf)
---

## 🚀 **Tech Stack**

- **Frontend**: 
  - 🔥 **React JS**
  - 🌪️ **Tailwind CSS** 
  - ✨ **Lottie Animations**
  - 🎬 **React Animations** 

- **Backend**: 
  - 🔥 **Firebase** – Real-time database to store and manage user comments, feedback, and more!

---

## 🌟 **Features** ✨

- **Dark Theme Toggle** 🌙: Switch between light and dark mode for the perfect vibe.
- **Real-Time Comments** 💬: Share your thoughts instantly! Comments are updated in real-time.
- **Step-by-Step Download Option** 📥: Download the game smoothly with clear instructions on each step.
- **Routing & Navigation** 🔄: Smooth navigation throughout the site, with easy access to all pages.
- **Easy Content Updates** ✍️: Site content can be updated with a simple click by editing the content files! So you’ll always get the latest updates! 🔄
